# assets/village

Fond du menu graphique « Village » (thème `ui-village`).

- **`village-map.png`** — image de fond **non annotée**, panoramique du village.
  Ratio ~1024×585 (16:9-ish). Déposée par Jonathan. Les zones de clic sont
  calées en **pourcentages** dans le JS/CSS, donc une version plus grande au
  **même ratio** fonctionne sans changement.
